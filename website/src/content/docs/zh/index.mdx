## 核心工程准则

<CardGrid>
  <Card title="100% 模组无关内核" icon="approve-check">
    Forgia 核心零硬编码第三方模组 ID 或类名。所有模组专属优化均通过 `RegionAdapterApi` 与 `ParallelApi` 以独立兼容适配器实现。
  </Card>
  <Card title="安全闭环沙箱" icon="shield">
    Worker 在严格的空间与存储沙箱内运行（`DimensionDataStorage`、`BlockCapability`、`FakePlayer`、`EntitySection`），越界自动隔离回退，杜绝静默坏档。
  </Card>
  <Card title="模块化协调器架构" icon="puzzle">
    引擎拆分为方块实体、实体、刷怪、随机刻、跨区迁移、跨区传播、玩家前缀 7 大独立协调器，职责清晰、易于扩展维护。
  </Card>
  <Card title="内置全链路可观测性" icon="magnifier">
    内置 `/forgia bottleneck`、`/forgia status`、`/forgia fences`、`LowTpsProbe` 与 `SandboxDemotionProbe`，无需外挂工具即可秒级定位瓶颈。
  </Card>
</CardGrid>
