## Five Fully Asynchronous Tick Slices

## Engineering Principles

<CardGrid>
  <Card title="100% Mod-Agnostic Core" icon="approve-check">
    Forgia core contains zero hardcoded third-party mod IDs or classes. Mod-specific optimizations live cleanly in standalone adapters built on `RegionAdapterApi` and `ParallelApi`.
  </Card>
  <Card title="Fail-Closed Ownership & Sandbox" icon="shield">
    Region workers operate inside strict spatial and storage sandboxes (`DimensionDataStorage`, `BlockCapability`, `FakePlayer`, `EntitySection`) with automatic demotion instead of silent corruption.
  </Card>
  <Card title="Modular Coordinator Architecture" icon="puzzle">
    Execution is cleanly separated into dedicated coordinators for Block Entities, Entities, Spawning, Chunk Ticks, Transfers, Border Propagation, and Player Prefixes.
  </Card>
  <Card title="Built-In Observability" icon="magnifier">
    Diagnose live hotspots with `/forgia bottleneck`, `/forgia status`, `/forgia fences`, `LowTpsProbe`, and `SandboxDemotionProbe` without external profilers.
  </Card>
</CardGrid>
